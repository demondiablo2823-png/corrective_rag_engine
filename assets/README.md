# Assets Directory

This directory stores screenshot images and demonstration GIFs for the Streamlit web interface and retrieval pipeline.

## Recommended Files

- `home.png`: Screenshot of the landing page / document ingestion panel.
- `chat.png`: Screenshot of the active conversational chat interface.
- `sources.png`: Screenshot of the collapsible source attribution and metadata panel.
- `demo.gif`: Short (10-15s) demonstration recording showing document upload and question-answering in action.
